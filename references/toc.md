# 収録構成（章・節・項目）

アプリ `index.html` に収録している本文の構成。`<script type="application/json" id="bookData">` から機械的に生成した一覧で、
本文そのものは収録していない（本文はアプリ内のJSON、原典は [sources.md](sources.md) 参照）。

小見出しのない項目は、アプリの目次と同じく **（本文）** と表記した（節の本文がそのまま1項目になっているもの）。
アプリでは、この場合は節名がそのまま読み上げ画面のタイトルになる。
