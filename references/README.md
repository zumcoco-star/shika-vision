# references — 参考資料

歯科ビジョン読み上げ (`../index.html`) の**元になった資料と、その扱い方**をまとめておく場所。
アプリの動作には一切関与しない読み物用のフォルダで、ここを削除してもアプリはそのまま動く。

## 置いてあるもの

| ファイル | 内容 |
|---|---|
| [sources.md](sources.md) | 原典（日本歯科医師会「2040年を見据えた歯科ビジョン」）の書誌情報と入手先 |
| [toc.md](toc.md) | アプリに収録した本文の構成。章・節・項目の一覧と、項目ごとの本文字数・図表数 |
| [figures.md](figures.md) | 図表一覧（58件）。アプリは図表そのものを収録していないため、原典で図を確認するときの索引 |
| [data-notes.md](data-notes.md) | 本文データの作り方と、現時点で分かっている本文データの不具合 |

`toc.md` と `figures.md` は `index.html` 内の本文JSON（`id="bookData"`）から機械的に起こしたもの。
本文を作り直したら、この2つも作り直す。

## このフォルダの決まり

> ⚠️ **`.gitignore` は「これから追加するファイル」にしか効かない。**
> 一度コミットしたファイルは、あとから除外設定を足しても追跡され続ける
> （2026-09-19 に原典PDF 4本がこの状態で見つかった）。
> 資料を置く前に `git check-ignore -v <ファイル>` で確認し、
> 誤って入れてしまったら `git rm --cached <ファイル>` で追跡を外すこと。



**このリポジトリは public**（ルートの [CLAUDE.md](../CLAUDE.md) を参照）。それを前提に：

- 原典PDFなどの**配布物そのものはコミットしない**。書誌情報とリンクだけを置く。
  作業のため手元にPDFを置く場合に備えて、`.gitignore` で PDF などを除外してある
- 個人情報・所属先の内部情報・認証情報は、メモ書きであっても書かない
- 置くのは Markdown のテキストのみ。アプリは単一HTMLファイル完結を保つので、
  ここのファイルを `index.html` から読み込むことはしない
