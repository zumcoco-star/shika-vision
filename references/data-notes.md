# 本文データについて

## どこに入っているか

`../index.html` 内の `<script type="application/json" id="bookData">` の1か所だけ。
外部ファイルもCDNも使わず、単一HTMLファイルで完結させるための構成。

```
meta                      … 表題・発行者・注記（画面に常時表示する出典）
chapters[]                … 章（4）
 └ sections[]             … 節（19）
    └ items[]             … 項目（45）
       └ blocks[]         … ["種別", "テキスト"] の配列
```

`blocks` の種別は5つ。

| 種別 | 中身 |
|---|---|
| `p` | 段落 |
| `li` | 箇条書きの1行 |
| `h4` | 項目内の小見出し |
| `fig` | 図表番号＋キャプション（設定で読み飛ばせる） |
| `note` | 注記（`＊`で始まる補足） |

## 現状の数字（2026-09-10 時点）

4章 / 19節 / 45項目 / 本文 約64,000字 / 図表キャプション 58件（図表1〜57＋番号なしの補足1件）。
章ごとの内訳は [toc.md](toc.md)。

## 作り方（原典PDF → JSON）

ルートの [CLAUDE.md](../CLAUDE.md) に書いてある手順の詳細版。

1. PDFをローカルに取得できる章は `pypdfium2` でページ単位にテキスト抽出する
2. ファイルサイズ等の都合で直接ダウンロードできない章は、別経路で取得したテキストを使う
3. **どちらの経路でも、ページ末尾に次ページ冒頭の数行が先読みで混入する。**
   行単位で重なりを検出して落としてから段落を再構成する（この処理を省くと本文が二重になる）
4. 章 → 節 → 項目に切り分け、図表キャプションを `fig` ブロックとして本文から分離する

**本文の修正はこのJSONを直接いじらず、生成手順からやり直す。**

## 分かっている不具合

先読み混入の除去が完全ではなく、**図表キャプションのブロックに次ページ本文の冒頭が取り込まれている**箇所が
第4章に4か所ある。同じ文は `p` ブロック側には存在しない（本文が二重になっているのではなく、
本文の一部が図表キャプション側に入り込んでいる）。

そのため、**設定で「図表キャプションを読む」をオフにすると、その本文が読み上げられない。**

| 箇所 | キャプションのあとに続いてしまっている本文 |
|---|---|
| 図表34（第4章 1）かかりつけ歯科医の養成…） | 「中心となって、研修体制を整備する。その際、座学のみならず…」 |
| 図表39（第4章 3）医科歯科連携をはじめとする…） | 「占めており、ほとんどの病院歯科において少人数で…」 |
| 図表40（第4章 4）介護、障害福祉関係機関との連携強化） | 「り、全国の医療的ケア児は約1.8万人と推計されている…」以降（約400字と長い） |
| 図表52（第4章 6）歯科医師の資質の維持・向上…） | 「て重要であることは論を俟たず、日本歯科医師会では…」 |

そのほか気づいた点（いずれも読み上げが止まる類の不具合ではない）。

- 図表46・47 はキャプションが空で、番号だけになっている
- 第4章に、図表35 → 図表34、図表56 → 図表55 の順で並んでいる箇所がある（原典の図版配置由来と思われる）
- 「図表1」＋「12歳児の…」のように番号とキャプションの間に区切り文字がないため、
  読み上げでは番号と本文が続けて発話される
- 第4章のオーラルフレイルの項に、番号のない `fig` ブロック（前の図表の出典の続き）が1件ある
