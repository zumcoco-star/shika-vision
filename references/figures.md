# 図表一覧（アプリ未収録）

アプリは**図表そのものを収録していない**。読み上げるのは図表番号とキャプションだけなので、
グラフや図の中身を確認するときは原典PDF（[sources.md](sources.md)）の該当図表を参照する。

収録している図表キャプションは 58 件（図表1〜57 ＋ 番号のない補足1件）。
並び順はアプリ内での出現順。第4章には番号が前後している箇所がある（図表35→34、図表56→55）。
図表のない第3章は表を載せていない。

凡例：⚠ = キャプションの末尾に本文の一部が取り込まれている箇所（[data-notes.md](data-notes.md) 参照）
