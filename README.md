# shika-vision

ブラウザだけで動く読み上げアプリ集。それぞれ HTML 1ファイルで完結し、開くだけで使えます(インストール・ビルド不要)。

| アプリ | 公開URL |
|---|---|
| 歯科ビジョン読み上げ | https://zumcoco-star.github.io/shika-vision/ |
| 画像よみあげ | https://zumcoco-star.github.io/shika-vision/yomiage.html |

iPhone / iPad では Safari の「ホーム画面に追加」でアプリのように使えます(それぞれ別々に追加できます)。

## 歯科ビジョン読み上げ (`index.html`)

日本歯科医師会「2040年を見据えた歯科ビジョン ― 令和における歯科医療の姿 ―」(2020年10月公表)の
本文全4章を収録し、端末の音声で読み上げるアプリ。通勤中や移動中に「聞いて」読めるようにするためのもの。

- **目次から選んで再生**: 章 → 節(柱) → 項目の3階層。全4章・19節・45項目を収録(本文 約6.9万字)
- **文単位で読み上げ**: 読んでいる文をハイライト。文をタップするとそこから再生
- **操作**: 再生/停止・前後の文・前後の項目・速度(0.7〜1.6倍)・声の選択
- **続きから読む**: 最後に読んだ位置を記憶し、次回起動時にワンタップで再開
- **本文検索**: 全文からキーワード検索し、ヒット箇所の項目へジャンプ
- **設定**: 文字サイズ、画面テーマ(自動/明るい/暗い)、図表キャプションを読むか、
  項目をまたいで続けて読むか、再生中に画面を消さない(Wake Lock)、スリープタイマー(10〜60分)
- 設定・しおりはブラウザの localStorage(`vision2040-yomiage-v1`)にのみ保存(外部送信なし)
- **図表そのものは収録しておらず**、図表番号とキャプションのみ読み上げます。
  正確な内容・グラフは原典PDFを参照してください

## 画像よみあげ (`yomiage.html`)

書類・本・貼り紙などを撮影(または写真から選択)して保存すると、文字を自動で読み取り、
音声で音読してくれるアプリです。

- 画像を追加すると自動でOCR(文字読み取り)が走り、▶ボタンで音読開始
- 文単位のハイライト表示、文をタップするとそこから読み上げ
- 読み取り結果は編集でき、修正後の内容で音読される(再読み取り・縦書きモードあり)
- 速度調整と声の選択(端末に「拡張」音声を入れるとより自然な声になります。
  iPhoneは 設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語)
- **画像・テキストは端末内(IndexedDB / localStorage)にのみ保存され、外部送信されません。**
  文字読み取りも端末内で実行します(読み取りプログラムと日本語データのみ初回にCDNから取得・計約4MB)
- 初回のみネット接続が必要。以降はオフラインでも読み取り・音読できます

## 音声について(両アプリ共通)

端末内(オフライン)の音声を優先して使います。ブラウザがネット経由で提供する音声は
「(オンライン音声)」と明示ラベルを付け、**自分で選んだ場合のみ**使われます。
読み上げテキストが端末の外に出るのは、その音声を選んだ場合だけです。
